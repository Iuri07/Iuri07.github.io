medplan / schedule.ts / aulaPriority

cálculo dos pesos

como o medplan decide quantas questões cada aula recebe na semana. três sinais: incidência (quão recorrente é o tópico no banco), fraqueza (o quanto você erra) e o cap diário (não sobrecarregar um dia).

①fórmula principal

priority = baseWeight × (0.5 + weakness)

baseWeight mede incidência (em 1..~30). weakness vive em 0..1 (0 = domina, 1 = zero acerto). O +0.5 evita que aula 100% dominada zere — multiplier final vai de 0.5× a 1.5×.

②baseWeight — incidência

Três fontes, em ordem de preferência:

├
se totalQuestions > 0 → √totalQuestions (sync de incidência rodou — usa contagem real do banco)
├
senão se há tier → TIER_WEIGHT[incidenceTier] (fallback do cronograma)
└
default → 4 (sem info nenhuma)

O √ amortece tópicos gigantes: 400 questões = √400 = 20; 40 questões = √40 ≈ 6.3. Diferença vira ~3× em vez de 10×.

③weakness — performance

Combina dois sinais. latestReviewPct é o pct da revisão mais recente feita no medplan (varre A4 → A3 → A2 → A1, pega o primeiro nível com nota registrada). accuracyPct vem dos cadernos do Estratégia, sincronizado no walk de classificações (sinal mais amplo, geralmente mais antigo).

├
se ambos existem → effective = avg(accuracyPct, latestReviewPct)
├
se só revisão → effective = latestReviewPct
├
se só caderno → effective = accuracyPct
└
nenhum → weakness = 0.5 (default neutro)
weakness = max(0, 1 − effective / 100)

④orçamento semanal

Greedy: ordena aulas pendentes por priority DESC (tiebreak dueDate ASC — overdue ganha). Inclui do topo até o bottom enquanto a parcela da próxima aula ≥ perAulaMin (default 4). Resto fica de fora (não recebe questão essa semana).

share_i = weeklyBudget × priority_i / Σpriority_incluídas

Para fechar exatamente no weeklyBudget: largest-remainder. Pisa em floor(share), depois distribui as sobras pras aulas com maior parte fracionária.

⑤cap diário

Caminha dia a dia. Pra cada dia: sort por priority desc, enche até bater perDayMax. O que sobrar vai pro próximo dia com folga; se nenhum tem, vai pro com menos carga (espalha overflow). Último dia da janela aceita o excedente.
